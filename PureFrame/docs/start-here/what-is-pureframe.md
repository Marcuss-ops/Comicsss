# What is PureFrame?

PureFrame is a programmatic video rendering engine built on TypeScript and Node.js.

## Key Features

- **Deterministic Rendering**: Same input always produces same output
- **TypeScript First**: Full type safety and IntelliSense support
- **Skia Powered**: Hardware-accelerated 2D graphics via Skia
- **Modular Architecture**: Core, Media, Render, and Visuals packages
- **FFmpeg Export**: Professional video encoding

## Use Cases

- Social media content automation
- Data visualization videos
- Procedural animations
- Template-based video generation
